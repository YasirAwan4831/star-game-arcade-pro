# 🤝 Contributing to Star Game

First of all, thank you for considering contributing to **Star Game** ⭐  
Your support, ideas, improvements and contributions help make this project better for everyone.

We welcome all kinds of contributions including:

- 🐛 Bug Fixes
- ✨ New Features
- 🎨 UI/UX Improvements
- ⚡ Performance Optimizations
- 📱 Responsive Enhancements
- 📖 Documentation Updates
- 🔊 Audio Improvements
- 🧩 Gameplay Ideas

---

# 📌 Project Goal

The goal of this project is to create a fun, modern, responsive, and advanced browser-based arcade game using:

- HTML5
- CSS3
- Vanilla JavaScript

This project is fully open-source and beginner-friendly.

---

# 🚀 Getting Started

## 1️⃣ Fork the Repository

Click the **Fork** button at the top-right corner of the repository.

---

## 2️⃣ Clone Your Fork

```bash
git clone https://github.com/your-username/star-game-arcade-pro.git
```

---

## 3️⃣ Open the Project

```bash
cd star-game-arcade-pro
```

---

## 4️⃣ Run the Game

Open:

```bash
index.html
```

in your browser.

---

# 🌱 Create a New Branch

Before making changes, create a separate branch:

```bash
git checkout -b feature/your-feature-name
```

Example:

```bash
git checkout -b feature/add-powerups
```

---

# 🛠 Contribution Guidelines

Please follow these rules while contributing:

## ✅ Code Style

- Write clean and readable code
- Use meaningful variable names
- Add comments where necessary
- Keep functions modular
- Avoid unnecessary code duplication

---

## ✅ UI/UX Improvements

Feel free to improve:

- Animations
- Colors
- Effects
- Responsive design
- Accessibility
- User experience

---

## ✅ JavaScript Guidelines

- Keep logic organized
- Avoid global variable pollution
- Optimize animations and loops
- Maintain performance

# 🐛 Reporting Bugs

If you find a bug:

1. Open an issue

4. Describe reproduction steps

# ✨ Pull Request Process

## 1️⃣ Commit Changes

```bash
git commit -m "Added new feature"
```

---

## 2️⃣ Push Branch

```bash
git push origin feature/your-feature-name
```

---

## 3️⃣ Open Pull Request

Submit a pull request with:

- Clear title
- Proper description
- Screenshots (if UI changes)
